1. Extract the data from the hosting service¶

In the cell below, define a function extract_cifar_data that extracts python version of the CIFAR-100 dataset. The CIFAR dataaset is open source and generously hosted by the University of Toronto at: https://www.cs.toronto.edu/~kriz/cifar-100-python.tar.gz

import requests

def extract_cifar_data(url, filename="cifar.tar.gz"):
    """A function for extracting the CIFAR-100 dataset and storing it as a gzipped file
    
    Arguments:
    url      -- the URL where the dataset is hosted
    filename -- the full path where the dataset will be written
    
    """
    
    # Todo: request the data from the data url
    # Hint: use `requests.get` method
    print(f"Downloading CIFAR-10 from {url}...")
    r = requests.get(url, stream=True)
    if r.status_code == 200:
        with open(filename, 'wb') as f:
            for chunk in r.iter_content(chunk_size=1024 * 1024): # 1MB chunks
                if chunk:
                    f.write(chunk)
        print(f"download completed: {filename}")
    else:
        print(f"Error: status code {r.status_code}")
        return

import os
from PIL import Image
import numpy as np
def save_images(image_data, filename, target_folder):
    # 1. Grab the image data (esto es una fila de 3072 valores)
    img = image_data
    
    # 2. Consolidated stacking/reshaping
    # CIFAR viene como (3, 32, 32). Transponemos a (32, 32, 3) para que sea una imagen válida
    target = img.reshape(3, 32, 32).transpose(1, 2, 0)
    
    # 3. Save the image
    # Creamos la carpeta si no existe
    if not os.path.exists(target_folder):
        os.makedirs(target_folder)
        
    # Convertimos el array de numpy a una imagen de PIL y la guardamos
    image_obj = Image.fromarray(target)
    image_obj.save(os.path.join(target_folder, filename))
    
    # Return any signal data for debugging
    return True

Model Training¶

For Image Classification, Sagemaker also expects metadata e.g. in the form of TSV files with labels and filepaths. We can generate these using our Pandas DataFrames from earlier:

In [30]:
def to_metadata_file(df, prefix):
    df["s3_path"] = df["filenames"]
    df["labels"] = df["labels"].apply(lambda x: 0 if x==8 else 1)
    return df[["row", "labels", "s3_path"]].to_csv(
        f"{prefix}.lst", sep="\t", index=False, header=False
    )
    
to_metadata_file(df_train.copy(), "train")
to_metadata_file(df_test.copy(), "test")

Using the bucket and region info we can get the latest prebuilt container to run our training job, and define an output location on our s3 bucket for the model. Use the image_uris function from the SageMaker SDK to retrieve the latest image-classification image below:

# Use the image_uris function to retrieve the latest 'image-classification' image

    region=region, 
    framework='image-classification', 
    version='latest' # También puedes usar '1' para la versión estable
)
s3_output_location = f"s3://{bucket}/{prefix}/models/image_model"

We're ready to create an estimator! Create an estimator img_classifier_model that uses one instance of ml.p3.2xlarge. Ensure that y ou use the output location we defined above - we'll be referring to that later!
